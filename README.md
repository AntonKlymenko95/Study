# Playwright Learning

Учебный репозиторий: прохожу курс по автоматизации тестирования на **Playwright + JavaScript**.
Цель — не идеальный код, а видимый прогресс: от первых тестов до нормальной архитектуры фреймворка.

## Стек

- [Playwright](https://playwright.dev/) — автотесты в браузере
- JavaScript (ES Modules)
- Page Object Model — страницы вынесены в отдельные классы
- `dotenv` — тестовые данные (креды) не хранятся в коде

## Структура

```
tests/          — тестовые сценарии
page-object/    — классы страниц (Login, Register, Catalog, Card)
data/           — тестовые данные
playwright.config.js
```

## Что покрыто сейчас

Сквозной сценарий (`tests/e2e.spec.js`):
1. Регистрация нового пользователя
2. Авторизация
3. Переход в каталог и выбор товара
4. Проверка деталей товара и итоговой цены на карточке

## Запуск

```bash
npm install
npx playwright test
```

UI-режим (с визуальным дебагом):

```bash
npx playwright test --ui
```

Перед запуском нужен файл `.env` в корне проекта (не коммитится, см. `.gitignore`):

```
NEW_USER_1_EMAIL=...
NEW_USER_1_PASSWORD=...
```
